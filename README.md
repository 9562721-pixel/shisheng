# 识生

辅导员看图记学生。一个 HTML 文件，用 Chrome 或 Edge 打开。照片和进度只留在这台电脑上。

下载：[shisheng.html](https://github.com/9562721-pixel/shisheng/raw/main/shisheng.html)

程序里左侧有「说明」。第一次打开会引导一次，关掉后不再出现。

## 打开

用 Chrome 或 Edge。不要用微信或 QQ 的内置浏览器，那些浏览器选不了文件夹。

把文件固定放在同一个位置再打开。挪到别的文件夹后，有的浏览器会当成另一个网站，进度会对不上。

## 链接照片文件夹

点「链接本机文件夹」，选中放证件照的目录。网页不能自己翻硬盘，所以必须你点一次。

- 读入后会压缩记在浏览器里。原照片不会被改，也不会上传。
- 文件夹里有新增、删除、改名，再点「重新读取」。
- 会跳过 `__MACOSX` 和以 `._` 开头的废文件。
- 还没链接时，练的是 24 人演示名册。链接之后换成你的学生。

## 文件名

只看文件名，不看脸。下划线分成六个空位：

```text
班级_姓名_学号_贫困_心理_籍贯_
```

例如 `电气研22_陈会益_2220310303___山东省_.jpg`：

电气研22、陈会益、2220310303、非困难、无关注、山东省。

- 学号必须是 8 到 12 位数字，才按这个格式认。
- 贫困、心理空着，就是非困难、无关注，不算错。
- 贫困认得：空、贫困、困难、非困难、非贫困、否、无。
- 心理认得：空、心理重点关注、心理关注、无关注、无、否。
- 写成不认识的词，或文件名里只有名字是对的，会进「核对」，不会装成已经认对，也不会瞎编班级和籍贯。
- 六个空位都在、学号也像学号，但班级或籍贯写错了，程序按空位照单全收。它只认位置。

核对里改完点「就这样」。更正按文件记住，同一个文件名下次不再问。

## 四种练法

- **口答。** 只给脸。先说班级、姓名、学号、贫困、心理、籍贯。空格揭晓。1 认不出，2 漏字段，3 全对。
- **反背。** 看名字，在四张脸里点出本人。
- **易混。** 长得像、名字像的人对打。
- **模考。** 抽 10 张，揭晓后记对或错。

冷门优先：名册里标过「少见面」的人先出现。点开名册里的照片可以标少见面。

## 进度存在哪

打分、模考、少见面、改过的词条和照片副本，都在这个浏览器里，不在 HTML 文件里。把文件拷给别人，不会把你的学生照片拷走。清掉浏览器里这个网站的数据，进度会丢。
