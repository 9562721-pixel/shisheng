# 识生 3.2 · 年度考核

面向辅导员的年度学生照片学习工具。上传上级部门的照片压缩包与考核信息表，核对后进行照片浏览、分组学习和模拟考核。程序为一个HTML文件，学生材料与学习记录保存在当前浏览器本机，无需账号或服务器。

[下载本次更新分支的识生3.2](https://github.com/9562721-pixel/shisheng/raw/refs/heads/codex/rapid-memory-flow/shisheng.html)。`index.html`与`shisheng.html`由同一份源码生成，内容相同。更新在独立分支及PR #1，原main版本保留，尚未合并或替换原在线版本。

## 本版更新

3.2新增数码冒险：独立游戏存档、首次100张宠物抽取券、客观答题金币、伙伴养成和首发前10个剧情节点。照片右上角的28×28像素放大按钮保持不变。

- **上级材料作为考核依据**：年度照片与原始信息表锁定保存，学习记录另行存储。上级更正材料时新增版本，不覆盖原有年度版本。
- **简化导入**：一个ZIP照片包与一张XLS/XLSX信息表即可预览匹配；仅冲突或未匹配照片需要核对，支持手动关联、忽略单张或忽略全部待核对照片。
- **照片总览**：在同一页连续展示全部筛选结果。信息默认隐藏；点击照片显示姓名、班级、家庭住址，再点隐藏。顶部“信息总开关”统一显示或隐藏当前筛选结果；部分显示时开启会统一显示，不会逐张取反。独立放大按钮可查看大图，信息隐藏时大图也不显示答案。显示状态仅在本次练习区打开期间保留，关闭重开后恢复隐藏，不改变材料、成绩或进度。
- **组合筛选**：班级、省份、贫困情况、心理情况可多选、组合，支持排除任意省份；不预设黑龙江或其他地区。省份无法识别时单独列出，不改写原始地址。
- **固定分组**：默认按信息表原顺序每组六人，保存分组及组内顺序，成绩不会重新排列学生。主动选择随机后保存随机结果，再次打开沿用；重新生成时保留旧计划。
- **学习计划与进度**：查看各组成员、自动完成与手动标记状态；设置每日组数、补记到指定组、调整下一组和备注。手动进度不生成考试成绩。
- **五人模拟考核**：按当前筛选随机抽取最多五人，分别练习姓名、班级或全部考核项。不虚构正式考试分数，不自动计时。采用单选题，完成后统一展示软件判分成绩与错项；分组学习即时反馈。旧自评仅作为历史保留。
- **独立使用**：默认放大练习区；返回后管理年度材料、备份和旧版资料。电脑与手机宽度均有布局适配。

## 数码冒险与独立存档

- 无照片也可选择亚古兽或加布兽、使用100张首次赠送券、抽取伙伴和挑战剧情。两条初始路线各四形态；重复伙伴是独立个体。
- SSR总概率2%、无保底，六种等概率。金币抽宠物60/次、装备30/件、升级30/级、装备强化15/级；配置集中于`src/v3/game-model.js`。
- 软件判分答对有效题奖励2金币；同一学号、字段、北京时间日期只发一次，换年度不刷新。每日六人练习与五人模考各10金币，每项一次，总上限120。无有效干扰项不出题；浏览照片、自评与手动进度不发金币。
- 游戏数据库`recognition-adventure-independent`与年度库、旧版库完全分开。更换材料、恢复考核备份不改动游戏资产。首次发券、扣款与结算收据在同一IndexedDB读写事务中保存，支持多窗口串行记账。
- “存档与说明”中单独导出/恢复游戏备份。恢复先预览再完整替换，不合并资产；不含学生姓名、照片、考核原表与作答。不同地址/浏览器/设备之间通过该文件迁移，无账号与云同步。
- 前10个节点开放文件岛与沙拔大陆，关主为恶魔兽和悟空兽。其余20个节点显示后续开放；没有学习百分比或综合考试锁关。强力SSR可在首日通关。
- 其他初始伙伴在首轮六人客观练习后赠送；前六轮依次赠送六位伙伴。宠物最多30级，初始路线在5/12/20级可进化；培养与装备保留。战斗免费，无可重复刷取金币。
- 像素素材来自[Wikimon Digimon Story档案](https://wikimon.net/Category:Digimon_Story_sprites)，数码宝贝角色及原游戏素材权利归原权利人。页面内提供来源说明；单文件内置静态图，无需额外下载。

## 准备材料

在“年度考核”选择年度，上传一个ZIP与一张XLS/XLSX。信息表包含以下七列表头，列顺序可不同，也可有表格标题行：

学号、姓名、班级、家庭住址、是否贫困生、心理情况、其他。

学号和姓名用于核对身份；其他空白考核项目按“无”处理。当前五项考核内容为姓名、班级、家庭住址、是否贫困生、心理情况；学号只作内部匹配，“其他”保留在原始表格与完整备份中，不进入本次自测。

照片支持JPG、PNG、WebP、GIF、BMP。文件名为学号、唯一姓名或原有`班级_姓名_学号_…`格式时可自动匹配。文件名中的贫困、心理、籍贯等内容不作为考核答案。重复学号、姓名冲突、多张照片不能通过最后一条覆盖的方式自动确定。

预览核对后确认锁定。缺照片学生保留在年度名单中，暂不参加照片练习。原始表格字节、照片、路径、匹配结果及校验一并保存，未匹配而被忽略的照片也保留。

## 备份与旧版资料

“查看考核资料与备份→导出当前考核完整备份”包含本年度原表、照片、匹配结果、分组、学习计划、当前练习和模考记录。恢复会新增独立副本，原有材料保留。与辅导员工作台的“年度考核”完整备份兼容，各年度请分别备份。

3.2沿用独立年度数据库`shisheng-annual-v3`，不会修改2.0的`shisheng-v2`或更早的`shisheng-folder`。

在“旧版资料”可检查当前地址原有的2.0名册，逐库导出原有`shisheng-backup`版本2备份，保留照片、文件名词条与旧进度。只在导出所选名册时读取相应照片。也可从新版中下载完整的2.0兼容程序，继续使用原来的文件夹流程或恢复旧JSON备份。旧资料不自动转换为上级考核事实。

更新前请在原使用地址导出备份。不同文件地址、浏览器或设备的数据可能相互隔离，不能保证复制HTML到新位置后自动读取旧数据。清理浏览器、更新或迁移前，请先导出备份并核对恢复结果。同一份考核资料请在一个窗口编辑。

## 运行与隐私

保存`shisheng.html`后使用较新的Chrome或Edge打开。全部执行资源已内置，不需要安装运行环境，不请求外部服务，不上传学生材料。练习区使用隔离页面及本机消息通道，仅接收考核字段、照片与进度；程序禁止外部网络连接。

完整备份含学生资料，请保存到受控位置。程序辅助个人学习，不代替正式学生评价或业务认定。联系使用问题：Leven，QQ：27040542；反馈时只提供操作步骤和去除学生信息后的报错。
